OCI Starter Skill

Use the OCI Starter skill to create and deploy applications on Oracle Cloud Infrastructure.

Easy installation · Examples · Manual installation

Easy installation

Codex: ask it to install the skill

Send this prompt in Codex:

Download and install the OCI Starter skill from
https://www.ocistarter.com/skill/oci-starter-skill.zip
for my user account.

Approve download and installation permissions if requested. If the skill does not appear after installation, restart Codex.

ChatGPT Desktop: upload through the UI

  1. Download the skill ZIP.
  2. Open Skills, select New Skill, then Upload from your computer.
  3. Select the ZIP and complete any review shown.
  4. Start a new chat and ask it to use OCI Starter.

Uploading registers the skill in ChatGPT; asking it to download the ZIP alone does not install it. The UI upload route is described in the official OpenAI instructions. Availability depends on your account and workspace settings.

OpenCode: ask it to install the skill

Download the OCI Starter skill from
https://www.ocistarter.com/skill/oci-starter-skill.zip
and install it in my global OpenCode skills directory.

For terminal commands, installation paths, Windows instructions, and troubleshooting, see Manual installation and fallback at the end of this page.

Manual installation and fallback

Use these instructions if prompt-based installation is unavailable or you prefer to install the files yourself. Codex and OpenCode discover skill folders on disk; ChatGPT Desktop uses the UI upload described above and manages its skills separately.

Windows notice: The Windows paths and PowerShell commands below are provided as a best-effort reference and have not been tested on Windows.

Codex: manual installation

macOS and Linux

Download the skill archive, then extract it into your global Codex skills directory:

mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cd "${CODEX_HOME:-$HOME/.codex}/skills"
curl -fL https://www.ocistarter.com/skill/oci-starter-skill.zip -o oci-starter-skill.zip
unzip oci-starter-skill.zip

Restart Codex desktop, then ask it to use $oci-starter-skill, for example:

Use $oci-starter-skill to create a Python application for Kubernetes with OCI Starter.

Windows (untested)

In PowerShell, download and extract the skill into %USERPROFILE%\.codex\skills:

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.codex\skills"
Set-Location "$env:USERPROFILE\.codex\skills"
Invoke-WebRequest "https://www.ocistarter.com/skill/oci-starter-skill.zip" -OutFile "oci-starter-skill.zip"
Expand-Archive -Force "oci-starter-skill.zip" .

Restart Codex desktop and use the same prompt shown above.

OpenCode: manual installation

OpenCode discovers directory-based skills that contain SKILL.md. Keep the folder name oci-starter-skill so its skill ID remains oci-starter-skill.

Global installation (macOS and Linux)

Download and extract the skill to make it available in all OpenCode projects:

mkdir -p "$HOME/.config/opencode/skills"
cd "$HOME/.config/opencode/skills"
curl -fL https://www.ocistarter.com/skill/oci-starter-skill.zip -o oci-starter-skill.zip
unzip oci-starter-skill.zip

Project installation (macOS and Linux)

Make the skill available only in one project. Replace my-project with your project directory:

mkdir -p my-project/.opencode/skills
cd my-project/.opencode/skills
curl -fL https://www.ocistarter.com/skill/oci-starter-skill.zip -o oci-starter-skill.zip
unzip oci-starter-skill.zip

Windows (untested)

Use the corresponding OpenCode skill directory, typically %USERPROFILE%\.config\opencode\skills for a global installation, or .opencode\skills within a project. For example, in PowerShell:

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.config\opencode\skills"
Set-Location "$env:USERPROFILE\.config\opencode\skills"
Invoke-WebRequest "https://www.ocistarter.com/skill/oci-starter-skill.zip" -OutFile "oci-starter-skill.zip"
Expand-Archive -Force "oci-starter-skill.zip" .

Restart OpenCode, then request the skill by name:

Use the oci-starter-skill to create a Python application for Kubernetes with OCI Starter.

Verify and troubleshoot

  • Confirm the installed directory is named oci-starter-skill and directly contains SKILL.md.
  • Confirm the installed copy also contains scripts/oci_starter_url.py and references/options.md.
  • Restart the relevant desktop app after installing or updating the skill.
  • If the skill is not discovered, check for an accidentally nested path such as oci-starter-skill/oci-starter-skill/SKILL.md.
  • When updating an installation, download a fresh copy of oci-starter-skill.zip, replace the existing skill folder, and restart the app.

For product-specific availability and upload permissions, see the official OpenAI skills guide and the OpenCode skills documentation.
